## Featured Project

### ModelBudget — LLM Governance Gateway

**Python | FastAPI | PostgreSQL | Redis | Docker | Terraform | AWS**

ModelBudget is a production-style gateway for managing team access to Large Language Models while controlling usage and cost.

Key features:

- Built REST APIs using Python and FastAPI.
- Added team-level AI budgets and usage tracking.
- Implemented request rate limiting with Redis.
- Added circuit-breaker protection for provider failures.
- Created versioned prompt-management workflows.
- Recorded model usage, request results, and estimated costs.
- Built a secured, read-only operator dashboard.
- Used PostgreSQL with SQLAlchemy and Alembic migrations.
- Containerized the application with Docker Compose.
- Deployed the system on AWS using Terraform, EC2, CloudFront, and Systems Manager Parameter Store.
- Added automated testing and CI checks with GitHub Actions.
- Tested container restarts, EC2 stop/start recovery, database persistence, authentication, and HTTPS access.

This project gave me hands-on experience building and operating a complete backend system—from API and database design to cloud deployment, security, testing, and production troubleshooting.
