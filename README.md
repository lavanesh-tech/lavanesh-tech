## Featured Projects

### AgentABI — Agent Compatibility & Upgrade Intelligence Platform

**Python | FastAPI | PostgreSQL | Redis | Kafka | Neo4j | OpenAI | Docker | Kubernetes | Terraform | GCP**

AgentABI is a production-style platform for evaluating whether changes to an AI-agent system are safe to deploy.

It analyzes changes to models, prompts, tools, APIs, schemas, policies, and workflows using deterministic compatibility analysis, dependency graphs, historical execution replay, and differential analysis.

**Key features:**

- Built backend APIs with **Python, FastAPI, Pydantic, SQLAlchemy, and PostgreSQL**.
- Developed deterministic schema and configuration diffing for compatibility analysis.
- Used **Neo4j** to model component dependencies and calculate change blast radius.
- Built historical trajectory replay and differential analysis for comparing agent behavior.
- Implemented a deterministic risk engine that produces **PASS, WARN, or BLOCK** decisions.
- Integrated **OpenAI** for evidence-based explanations while keeping deployment decisions deterministic.
- Used **Kafka and Redis** for event-driven processing, caching, rate limiting, and temporary state.
- Implemented **JWT authentication, GitHub OAuth2, RBAC, tenant isolation, webhook verification, and audit logging**.
- Added observability using **OpenTelemetry, Prometheus, Grafana, and structured logging**.
- Built the frontend with **Next.js, React, TypeScript, and TanStack Query**.
- Containerized the platform with **Docker** and deployed it on **Google Kubernetes Engine (GKE)**.
- Provisioned GCP infrastructure with **Terraform** and deployed Kubernetes workloads using **Helm**.
- Built CI/CD pipelines with **GitHub Actions**, including automated testing, type checking, Docker builds, Terraform validation, secret scanning, vulnerability scanning, and IaC security scanning.

**Core design principle:** Deterministic software calculates compatibility and deployment risk. LLMs explain the evidence.

### ModelBudget — LLM Governance Gateway

**Python | FastAPI | PostgreSQL | Redis | Docker | Terraform | AWS**

ModelBudget is a production-style backend platform for managing team access to Large Language Models while controlling usage, reliability, and cost.

**Key features:**

- Built REST APIs using **Python and FastAPI**.
- Implemented team-level AI budgets and usage tracking.
- Added request rate limiting using **Redis**.
- Implemented circuit-breaker protection for LLM provider failures.
- Built versioned prompt-management workflows.
- Recorded model usage, request results, and estimated costs.
- Created a secured, read-only operator dashboard.
- Used **PostgreSQL, SQLAlchemy, and Alembic** for persistence and database migrations.
- Containerized the application using **Docker Compose**.
- Provisioned and deployed infrastructure on **AWS using Terraform**.
- Used **EC2, CloudFront, and AWS Systems Manager Parameter Store**.
- Added automated testing and CI checks with **GitHub Actions**.
- Tested container restarts, EC2 stop/start recovery, database persistence, authentication, and HTTPS access.

ModelBudget gave me hands-on experience building and operating a complete backend system, from API and database design to cloud deployment, security, testing, reliability, and production troubleshooting.
